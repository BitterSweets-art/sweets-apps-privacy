# システム手帳 サポート

> 最終更新日：2026年8月1日

## アプリ概要

システム手帳は、紙のシステム手帳の使い心地を iPhone・iPad で再現するアプリです。バインダーにリフィルを差し替える感覚で、デイリーページ・スケジュール・タスクを1冊にまとめて扱えます。

## 動作環境

- 対応OS：iOS 18 以上
- 対応端末：iPhone・iPad

## 主な機能

| 機能 | 内容 |
|---|---|
| 手帳ホーム | バインダー形式のホームから各リフィルを開きます |
| デイリーリフィル | その日の予定・タスクを1ページにまとめて表示します |
| タスク管理 | 優先度（A/B/C）と着手状況でタスクを整理します |
| カレンダー連携 | iOS 標準カレンダーの予定を、手帳のスケジュール欄に統合表示します |
| リフィル | 用途に応じたリフィルを選んで手帳を構成します |

## よくある質問（FAQ）

### Q1. 手帳に書いた内容は外部に送信されますか？

いいえ。手帳の内容（予定・タスクなど）はお使いのデバイス内でのみ扱われ、開発者のサーバーへ送信されることはありません。

なお、アプリの改善のために、匿名の利用状況データ（どの機能が使われたか）を PostHog へ送信しています。手帳に記入した内容は含まれません。詳しくは[プライバシーポリシー](./)をご覧ください。

### Q2. カレンダーの予定が表示されません

以下をご確認ください。

1. 設定画面の**「カレンダー連携」がONになっているか**
2. カレンダーへのアクセスを**許可**しているか（設定アプリ →「システム手帳」から確認できます）
3. 表示している日付に予定が登録されているか

カレンダー連携をONにした時点でアクセスの許可を求めます。許可しない場合も、アプリ内のスケジュール機能はそのままご利用いただけます。

### Q3. アプリからカレンダーに予定を書き込めますか？

**現在のバージョンでは、カレンダーへの書き込みには対応していません。** 読み込んで統合表示する機能のみを提供しています。

### Q4. 写真ライブラリへのアクセスは必要ですか？

**現在のバージョンでは、写真ライブラリへのアクセスは行いません。**

### Q5. iPhone と iPad でデータを共有できますか？

**現在のバージョンでは、端末間のデータ同期には対応していません。**

### Q6. データを削除したい

アプリをアンインストールすると、デバイス上の手帳のデータと設定はすべて削除されます。カレンダー本体の予定は本アプリでは複製・保持していないため、影響はありません。
