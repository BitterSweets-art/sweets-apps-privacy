# シフト管理エージェント サポート

> 最終更新日：2026年8月1日

## アプリ概要

シフト管理エージェントは、店舗・事業所のシフト作成と共有を1つのアプリにまとめた iOS アプリです。管理職とスタッフで表示が切り替わり、管理職はシフトの作成・調整を、スタッフは自分のシフト確認・希望の提出・打刻を行えます。

## 動作環境

- 対応OS：iOS 18 以上
- 対応端末：iPhone・iPad

## 主な機能

| 機能 | 内容 |
|---|---|
| 役割別の画面 | 管理職とスタッフで、それぞれに必要な画面を表示します |
| シフトの作成・確認 | 15分単位で確定シフトを組み、週・月の単位で確認できます |
| 希望の提出 | スタッフが勤務の希望を提出できます |
| 変更申請 | 確定後のシフトについて変更を申請・確認できます |
| 公開枠 | 埋まっていない枠を公開し、応募を受け付けます |
| 打刻 | 出勤・休憩・退勤を記録します |
| 組織の切り替え | 複数の組織に所属している場合に切り替えられます |

## よくある質問（FAQ）

### Q1. 入力したシフトや打刻の情報は外部に送信されますか？

いいえ。**現在のバージョンでは、シフト・希望・打刻・組織などの情報はお使いのデバイス内でのみ扱われ、開発者のサーバーへ送信されることはありません。** アプリ内に外部サーバーと通信する処理を含んでいません。

サーバー連携に対応する際は、[プライバシーポリシー](./)を更新してお知らせします。

### Q2. ほかのメンバーとシフトを共有できますか？

**現在のバージョンでは、端末をまたいだ共有・同期には対応していません。** 組織やメンバーの情報はデバイス内で扱われます。

### Q3. サインインに使うメールアドレスとパスワードはどこに保存されますか？

**保存されません。** 入力された内容はデバイス内での照合にのみ使用し、開発者のサーバーへ送信することもありません。

### Q4. カメラや位置情報へのアクセスは必要ですか？

**いいえ。現在のバージョンでは、追加の権限を一切要求しません。**

### Q5. 打刻の記録はどこに残りますか？

現在のバージョンでは、打刻の記録はアプリの動作中にデバイス内で扱われます。サーバーへ保管する仕組みは導入されていません。

### Q6. データを削除したい

アプリをアンインストールすると、デバイス上のデータは削除されます。開発者側にお客様のデータは保管されていません。
